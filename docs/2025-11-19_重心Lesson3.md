# Lindy Hop 上課筆記 — 2025.11.19 重心 Lesson 3

## 複習一：左右前後的跳蹲

**右腳往前跳蹲要加強**：重心壓下去跳，然後腳換重心

**右腳往後跳蹲要加強**：
- 重心往後壓下去，要記得跳起來
- 然後重心換左腳（記得不要抬膝蓋）
- 右腳順勢往後放
- 然後記得煞車

除非是要往後走，才不用煞車

P.S. 不要做成 eagle slide；記得要跳起來
